AI Workbench Architecture

Log triage agent for the Nebius x NVIDIA Global AI Hackathon. A failed infrastructure log goes in; a diagnosis grounded in your own runbooks comes out, and any risky fix waits for a human.

Built and tested (15 Oct) Planned for the submission After 30 October

One triage, step by step

  1. A failed Ansible or Terraform log arrives at POST /triage.
  2. The app keeps only the error-bearing lines and embeds them with Qwen3-Embedding on Token Factory.
  3. Postgres returns the closest runbooks. Vector search finds the right one for all 14 test logs; BM25 is added to widen close calls on exact error strings.
  4. The graph adds related runbooks, such as "check the S3 backend" when credentials look wrong.
  5. Nemotron Super writes the cause, the fix and the risky step. With no runbook match, it can search the web through Tavily.
  6. The risky step waits for your approval, and the run is recorded.
